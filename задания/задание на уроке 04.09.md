
# 🟢 Задание 1. Проверка числа

Напиши функцию `check_number`, которая принимает одно число.

Функция должна определить:

* если число больше `0` — вернуть `"Число положительное"`
* если число меньше `0` — вернуть `"Число отрицательное"`
* если число равно `0` — вернуть `"Число равно нулю"`

После создания функции вызови её несколько раз с разными числами:

* `10`
* `-5`
* `0`

Пример результата:

```text
Число положительное
Число отрицательное
Число равно нулю
```

### 💡 Что здесь закрепляем

```text
аргумент → функция → if/elif/else → return → результат
```

# 🟢 Задание 2. Расчёт стоимости

Создай функцию `calculate_price`, которая принимает:

* цену одного товара;
* количество товаров.

Функция должна посчитать общую стоимость и **вернуть результат**.

Например, если цена товара `200`, а количество `3`, функция должна вернуть `600`.

После этого вызови функцию несколько раз:

```text
Цена: 200
Количество: 3
Стоимость: 600
```

и:

```text
Цена: 500
Количество: 2
Стоимость: 1000
```

### ⭐ Дополнительно

Добавь в функцию проверку количества:

* если количество больше `0` — посчитать стоимость;
* если количество равно `0` или меньше — вернуть сообщение `"Количество должно быть больше нуля"`.
