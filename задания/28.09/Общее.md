

Напиши программу «Заметка».

Пользователь вводит текст заметки.

Программа должна:

1. Получить текст через `input()`.
2. Открыть `notes.txt` через `with`.
3. Записать туда заметку.
4. Вывести сообщение об успешном сохранении.
5. Затем снова открыть этот файл через `with`.
6. Прочитать заметку.
7. Вывести её на экран.

### 💡 Подсказки

Здесь нужно использовать **два отдельных `with`**:

* первый — для записи;
* второй — для чтения.

Не пытайся читать файл в том же блоке, где записываешь его. Сначала закончи запись и выйди из первого `with`, затем открой файл заново.
