## 🟢 Задание 1. Сохранение оценок

Создай список оценок:

```python
grades = [5, 4, 3, 5, 4, 5]
```

Программа должна:

1. Открыть файл `grades.txt` через `with`.
2. Записать каждую оценку на отдельной строке.
3. Вывести:
   `Оценки сохранены!`
4. Снова открыть файл через `with`.
5. Прочитать оценки.
6. Вывести их на экран.

### 💡 Подсказки

* Для записи используй `"w"`.
* Чтобы записать все оценки, понадобится `for`.
* Каждая оценка должна быть на новой строке.
* В файл можно записывать только строки, поэтому обрати внимание на тип данных.
* После записи используй второй `with` для чтения.
* Для чтения всего содержимого можно использовать `read()`.

⭐ **Дополнительно:** после чтения посчитать количество оценок.

## 🟡 Задание 2. Обработка файла с ценами

Создай файл `prices.txt`:

```text
100
250
80
300
150
```

Напиши программу, которая:

1. Открывает файл через `with`.
2. Читает все цены.
3. С помощью `for` обрабатывает каждую строку.
4. Преобразует каждую цену в число.
5. Считает общую стоимость всех товаров.
6. Выводит общую стоимость.

Используй `try/except`, чтобы программа не завершилась с ошибкой, если в файле вместо числа окажется текст.

### 💡 Подсказки

* Ошибка возникнет при попытке превратить текст в `int`.
* Преобразование строки в число помести в `try`.
* Для ошибки преобразования используй `ValueError`.
* Если встретилось неправильное значение, выведи:
  `Ошибка: найдено не число!`
* После обработки всех строк выведи итоговую сумму.

⭐ **Дополнительно:** посчитать, сколько корректных чисел было найдено в файле.
