## 🟢 Задание 1. Сохранение списка покупок

Создай список покупок:

```python
shopping = ["Хлеб", "Молоко", "Яблоки", "Сыр"]
```

Программа должна:

1. Открыть файл `shopping.txt` с помощью `with`.
2. Записать каждый товар на отдельной строке.
3. После записи вывести:
   `Список сохранён!`
4. Затем снова открыть файл через `with`.
5. Прочитать содержимое файла.
6. Вывести все товары на экран.

### 💡 Подсказки

* Для записи используй режим `"w"`.
* Для каждого товара используй `for`.
* Каждый товар должен находиться на отдельной строке.
* Для перехода на новую строку используй `\n`.
* Для чтения файла после записи понадобится второй `with`.
* Прочитать весь файл можно с помощью `read()`.

## 🟡 Задание 2. Сумма чисел из файла

Создай файл `numbers.txt` со следующими числами:

```text
15
20
8
12
25
```

Напиши программу, которая:

1. Открывает файл через `with`.
2. Читает все строки.
3. С помощью `for` проходит по каждому числу.
4. Преобразует строки в числа.
5. Считает сумму всех чисел.
6. Выводит результат после выхода из `with`.

### 💡 Подсказки

* Для чтения используй `"r"`.
* Получить все строки можно через `readlines()`.
* При чтении файла каждое значение будет строкой.
* Используй `int()`, чтобы получить число.
* Создай переменную `total` для хранения суммы.
* На каждой итерации добавляй очередное число к `total`.
