
## 🟢 Задание 1. Список дел

Создай программу для управления списком дел.

Начальный список:

```python
tasks = ["Сделать домашнее задание", "Погулять", "Прочитать книгу"]
```

Программа должна:

1. Написать функцию для вывода всех дел.
2. Написать функцию для добавления нового дела.
3. Пользователь вводит новое дело через `input()`.
4. Если пользователь ничего не ввёл — вывести сообщение об ошибке.
5. Написать функцию, которая получает номер дела и удаляет его из списка.
6. Использовать `try/except`, чтобы программа не завершалась, если вместо номера пользователь введёт текст.
7. После изменений вывести обновлённый список.

💡 **Подсказка:** помни, что пользователь вводит номер дела как строку, поэтому его нужно преобразовать в число. Также подумай, что произойдёт, если пользователь введёт номер, которого нет в списке.

## 🟢 Задание 2. Кошелёк

Создай программу для простого учёта денег.

Начальная сумма:

```python
balance = 1000
```

Программа должна содержать функции:

1. Функция пополнения баланса — получает сумму и возвращает новый баланс.
2. Функция покупки — получает баланс и стоимость покупки и возвращает новый баланс.
3. Пользователь выбирает действие:

   * `1` — пополнить баланс
   * `2` — совершить покупку
4. Получить сумму через `input()`.
5. Использовать `try/except`, если пользователь вместо числа вводит текст.
6. При покупке проверить, хватает ли денег.
7. После операции вывести текущий баланс.

💡 **Подсказка:** функции не должны самостоятельно запрашивать данные через `input()`. Пусть они получают необходимые значения через **аргументы**, выполняют расчёт и возвращают результат.

⭐ **Дополнительно:** добавить третье действие — вывести текущий баланс.
