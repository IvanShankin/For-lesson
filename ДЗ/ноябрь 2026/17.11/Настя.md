🧠 Практическая работа 1. Система учёта успеваемости
Задача: разработать программу для ведения электронного журнала учеников.


Требования к программе
1. При запуске программа должна выводить меню:
- добавить ученика;
- показать всех учеников;
- добавить оценку ученику;
- показать средний балл ученика;
- удалить ученика;
- сохранить журнал в файл;
- загрузить журнал из файла;
- завершить программу.
2. Информация об учениках должна храниться в словаре. У каждого ученика должны быть:
- имя;
- возраст;
- список оценок;
- изучаемые предметы.
3. При добавлении ученика:
- пользователь вводит имя и возраст;
- возраст должен быть числом больше 0;
- имя не должно быть пустым;
- нельзя добавить двух учеников с одинаковым именем.
4. При добавлении оценки:
- пользователь указывает имя ученика;
- вводит оценку от 1 до 5;
- оценка добавляется в список оценок ученика;
- если ученик не найден, программа должна сообщить об этом.
5. При просмотре среднего балла:
- программа должна вычислить среднее арифметическое оценок;
- если оценок нет, вывести соответствующее сообщение.
6. При удалении ученика необходимо проверить, существует ли он.

7. Реализовать сохранение и загрузку журнала из файла с помощью with.

8. Разделить программу на функции. Для функций добавить аннотации типов.

9. Использовать try/except для обработки ошибок ввода и работы с файлами. Для некоторых некорректных ситуаций использовать raise.
Код программы с ошибками

```python

students = {}


def add_student(name: str, age: int) -> None:
    if name == "":
        raise ValueError("Имя не может быть пустым")

    if age < 0:
        raise ValueError("Возраст должен быть положительным")

    if name in students:
        print("Такой ученик уже существует")
        return

    students[name] = {
        "age": age,
        "grades": [],
        "subjects": set()
    }

    print("Ученик успешно добавлен")


def add_grade(name: str, grade: int) -> None:
    if name not in students:
        raise KeyError("Ученик не найден")

    if grade < 1 or grade > 5:
        raise ValueError("Оценка должна быть от 1 до 5")

    students[name]["grades"].append(grade)
    print("Оценка добавлена")


def show_students() -> None:
    if len(students) == 0:
        print("Список учеников пуст")
        return

    for name, info in students:
        print(f"Имя: {name}")
        print(f"Возраст: {info['age']}")
        print(f"Оценки: {info['grades']}")
        print(f"Предметы: {info['subjects']}")
        print("--------------------")


def calculate_average(name: str) -> float:
    if name not in students:
        raise KeyError("Ученик не найден")

    grades = students[name]["grades"]

    if len(grades) == 0:
        return 0

    total = 0

    for grade in grades:
        total = grade

    return total / len(grades)


def delete_student(name: str) -> None:
    if name not in students:
        print("Ученик не найден")
        return

    students.pop(name)
    print("Ученик удалён")


def save_students() -> None:
    with open("students.txt", "r", encoding="utf-8") as file:
        file.write(str(students))

    print("Журнал сохранён")


def load_students() -> None:
    with open("students.txt", "w", encoding="utf-8") as file:
        data = file.read()
        students = eval(data)

    print("Журнал загружен")


def main() -> None:
    while True:
        print("\n=== ЭЛЕКТРОННЫЙ ЖУРНАЛ ===")
        print("1. Добавить ученика")
        print("2. Показать учеников")
        print("3. Добавить оценку")
        print("4. Средний балл")
        print("5. Удалить ученика")
        print("6. Сохранить журнал")
        print("7. Загрузить журнал")
        print("0. Выход")

        choice = input("Выберите действие: ")

        try:
            if choice == "1":
                name = input("Имя ученика: ")
                age = input("Возраст: ")

                add_student(name, age)

            elif choice == "2":
                show_students()

            elif choice == "3":
                name = input("Имя ученика: ")
                grade = int(input("Оценка: "))
                add_grade(name, grade)

            elif choice == "4":
                name = input("Имя ученика: ")
                average = calculate_average(name)
                print(f"Средний балл: {average}")

            elif choice == "5":
                name = input("Имя ученика: ")
                delete_student(name)

            elif choice == "6":
                save_students()

            elif choice == "7":
                load_students()

            elif choice == "0":
                break

            else:
                print("Неизвестная команда")

        except ValueError:
            print("Ошибка: введены некорректные данные")

        except KeyError as error:
            print(error)

        except FileNotFoundError:
            print("Файл журнала не найден")


if __name__ == "__main__":
    main()

```
