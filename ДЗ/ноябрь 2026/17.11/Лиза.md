🧠 Практическая работа 2. Погодный помощник
Задача: разработать приложение, которое получает погоду в разных городах, сохраняет историю запросов и позволяет анализировать полученные данные.

Требования к программе
1. При запуске пользователь должен увидеть меню:
- узнать текущую погоду;
- посмотреть историю запросов;
- показать статистику;
- найти города с самой высокой температурой;
- завершить программу.
2. При получении погоды:
- запросить название города;
- отправить GET-запрос к wttr.in;
- получить JSON;
- вывести температуру, ощущаемую температуру, влажность, ветер и давление.
3. Обработать ошибки:
- проблемы с подключением к API;
- некорректный ответ API;
- отсутствие нужных данных;
- некорректный ввод пользователя.
4. После успешного запроса сохранить информацию о погоде в историю:
- город;
- температура;
- влажность;
- скорость ветра.
5. История должна храниться в списке словарей.

6. Реализовать статистику:
- количество выполненных запросов;
- средняя температура по всем запросам;
- самый холодный город;
- самый тёплый город.
7. Реализовать поиск городов, в которых температура выше заданной пользователем.

8. Сохранять историю запросов в файл через with. При следующем запуске программы история должна загружаться из файла.

9. Разделить программу на функции с аннотациями типов.

10. Использовать while, for, break, continue, if/elif/else, try/except и при необходимости raise.
Код программы с ошибками

```python 

import requests


history = []


def get_weather(city: str) -> dict:
    url = f"https://wttr.in/{city}?format=j1"

    response = requests.get(url)
    data = response.json()

    current = data["current_condition"][0]

    weather = {
        "city": city,
        "temperature": int(current["temp_C"]),
        "feels_like": int(current["FeelsLikeC"]),
        "humidity": int(current["humidity"]),
        "wind": int(current["windspeedKmph"]),
        "pressure": int(current["pressure"])
    }

    return weather


def show_weather(weather: dict) -> None:
    print("\n=== ПОГОДА ===")
    print(f"Город: {weather['city']}")
    print(f"Температура: {weather['temperature']} °C")
    print(f"Ощущается как: {weather['feels_like']} °C")
    print(f"Влажность: {weather['humidity']} %")
    print(f"Ветер: {weather['wind']} км/ч")
    print(f"Давление: {weather['pressure']} мбар")

    if weather["temperature"] < 0:
        print("На улице мороз!")
    elif weather["temperature"] < 15:
        print("Лучше надеть куртку")
    else:
        print("На улице тепло")


def save_history() -> None:
    with open("weather.txt", "w", encoding="utf-8") as file:
        for item in history:
            file.write(item + "\n")


def load_history() -> None:
    try:
        with open("weather.txt", "r", encoding="utf-8") as file:
            for line in file:
                history.append(line)

    except FileNotFoundError:
        print("История пока отсутствует")


def show_history() -> None:
    if len(history) == 0:
        print("История пуста")
        return

    for item in history:
        print(f"{item['city']}: {item['temperature']} °C")


def show_statistics() -> None:
    if len(history) == 0:
        print("Нет данных для статистики")
        return

    total = 0

    for item in history:
        total += item["temperature"]

    average = total / len(history)

    coldest = min(history)
    hottest = max(history)

    print("\n=== СТАТИСТИКА ===")
    print(f"Количество запросов: {len(history)}")
    print(f"Средняя температура: {average}")
    print(f"Самый холодный город: {coldest['city']}")
    print(f"Самый тёплый город: {hottest['city']}")


def find_warm_cities(min_temperature: int) -> None:
    print("\nГорода с температурой выше заданной:")

    for item in history:
        if item["temperature"] < min_temperature:
            continue

        print(
            f"{item['city']} — "
            f"{item['temperature']} °C"
        )


def main() -> None:
    load_history()

    while True:
        print("\n=== ПОГОДНЫЙ ПОМОЩНИК ===")
        print("1. Узнать погоду")
        print("2. История запросов")
        print("3. Статистика")
        print("4. Найти тёплые города")
        print("0. Выход")

        choice = input("Ваш выбор: ")

        try:
            if choice == "1":
                city = input("Введите город: ")

                weather = get_weather(city)
                show_weather(weather)

                history.append(weather)

            elif choice == "2":
                show_history()

            elif choice == "3":
                show_statistics()

            elif choice == "4":
                temperature = int(
                    input("Минимальная температура: ")
                )

                find_warm_cities(temperature)

            elif choice == "0":
                save_history()
                print("До свидания!")
                break

            else:
                print("Неверная команда")

        except ValueError:
            print("Ошибка ввода")

        except KeyError:
            print("Не удалось получить данные о погоде")

            
if __name__ == "__main__":
    main()
```
