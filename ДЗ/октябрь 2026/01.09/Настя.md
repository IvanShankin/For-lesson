# Список покупок

Создай небольшую программу для работы со списком покупок.

Используй словарь:

```python
products = {
    "Хлеб": 80,
    "Молоко": 100,
    "Яблоки": 150,
    "Сыр": 300
}
```

Число — это цена товара.

### 1. Вывести все товары

С помощью `for` выведи:

```text
Хлеб — 80 руб.
Молоко — 100 руб.
Яблоки — 150 руб.
Сыр — 300 руб.
```

### 2. Добавить покупку

Попроси пользователя ввести название товара.

Затем попроси ввести количество.

Например:

```text
Введите товар: Хлеб
Введите количество: 3
```

Программа должна рассчитать стоимость покупки.

В данном случае:

```text
Стоимость: 240 руб.
```

### 3. Обработать ошибки

Используй `try/except`.

Нужно обработать ситуацию, когда пользователь вместо количества вводит текст.

Например:

```text
Введите количество: три
Ошибка: количество должно быть числом!
```

Также проверь, существует ли введённый товар в словаре.

### 4. Создать функцию расчёта

Создай функцию, которая получает:

* цену товара;
* количество.

Функция должна вернуть итоговую стоимость.

### 5. Сохранить покупку в файл

После успешного расчёта открой файл `shopping.txt` через `with`.

Запиши туда информацию о покупке:

```text
Товар: Хлеб
Цена: 80 руб.
Количество: 3
Стоимость: 240 руб.
```

Если пользователь совершает несколько покупок, новые покупки должны **добавляться в файл**, а не удалять старые.

### 6. Посмотреть историю покупок

Добавь возможность прочитать файл `shopping.txt`.

Открой его через `with`, прочитай содержимое и выведи историю покупок на экран.

### 💡 Подсказки

* Для поиска товара используй ключи словаря.
* Сначала проверь, существует ли такой товар.
* Количество получаешь через `input()`, поэтому его нужно преобразовать в `int`.
* Преобразование лучше выполнять внутри `try`.
* Для расчёта используй отдельную функцию.
* Для добавления новых покупок в файл используй режим `"a"`.
* Для просмотра истории используй режим `"r"`.
* Внутри `with` находится работа непосредственно с открытым файлом.
* Для записи информации о покупке можно использовать несколько `write()`.
* Если хочешь вывести историю целиком, достаточно прочитать файл через `read()`.

⭐ **Дополнительно:** добавить возможность совершить несколько покупок подряд и завершить программу, когда пользователь введёт специальное слово, например `"стоп"`.
