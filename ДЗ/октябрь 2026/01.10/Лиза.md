# Электронный дневник

Создай программу для работы с оценками ученика.

Начальные данные:

```python
student = {
    "name": "Алексей",
    "grades": [5, 4, 3, 5, 4]
}
```

Программа должна уметь:

### 1. Выводить информацию об ученике

Вывести:

```text
Ученик: Алексей
Оценки: 5, 4, 3, 5, 4
```

Для вывода оценок используй цикл `for`.

### 2. Считать средний балл

Создай отдельную функцию, которая:

* получает список оценок;
* считает их сумму;
* считает количество оценок;
* возвращает средний балл.

### 3. Добавлять новую оценку

Попроси пользователя ввести новую оценку.

Проверь:

* является ли введённое значение числом;
* находится ли оно от `1` до `5`.

Если всё правильно — добавить оценку в список.

Используй `try/except`, чтобы обработать неправильный ввод.

### 4. Сохранить оценки в файл

После добавления оценки открой файл `grades.txt` **с помощью `with`**.

Запиши туда:

```text
Алексей
Оценки:
5
4
3
5
4
5
```

Каждая оценка должна находиться на отдельной строке.

### 5. Прочитать файл

После сохранения снова открой `grades.txt` через `with`.

Прочитай его содержимое и выведи на экран.

### 6. Итог

В конце программа должна вывести:

```text
Средний балл: 4.3
Данные сохранены в файл!
```

### 💡 Подсказки

* Раздели программу на несколько функций.
* Функция расчёта среднего должна использовать `return`.
* `input()` возвращает строку, поэтому оценку нужно преобразовать в `int`.
* Ошибка при преобразовании числа обрабатывается через `try/except`.
* Для записи используй режим `"w"`.
* Для чтения используй режим `"r"`.
* Для каждой оценки используй `for`.
* Не нужно использовать `file.close()` — `with` сделает это самостоятельно.
* Для записи нескольких строк можно использовать `\n`.

⭐ **Дополнительно:** если средний балл больше или равен `4.5`, вывести `"Отличный результат!"`, иначе — `"Есть что улучшить!"`.
