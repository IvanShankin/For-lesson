

## Метеостанция

Цель: создать программу, которая позволяет пользователю узнавать погоду в разных городах, пока он сам не решит завершить работу.

### Что нужно сделать

1. При запуске программы попроси пользователя ввести название города.
2. Отправь GET-запрос к API `wttr.in` и получи данные в формате JSON.
3. Выведи информацию о погоде:
   - название города;
   - температуру;
   - ощущаемую температуру;
   - влажность;
   - скорость ветра;
   - атмосферное давление.
4. После вывода погоды спроси пользователя, хочет ли он узнать погоду ещё в одном городе.
5. Если пользователь согласен, программа должна снова запросить город. Если отказывается — завершить работу.
6. Добавь обработку ошибок через `try/except`. Если город не найден или возникла ошибка при получении данных, выведи понятное сообщение вместо того, чтобы программа аварийно завершалась.
7. Добавь проверку температуры и выведи подходящую рекомендацию:
   - ниже 0 °C — посоветуй одеться теплее;
   - от 0 до 15 °C включительно — посоветуй взять куртку;
   - выше 15 °C — сообщи, что на улице достаточно тепло.

### Пример работы

```
=== Метеостанция ===

Введите город: Helsinki

Город: Helsinki
Температура: 8 °C
Ощущается как: 5 °C
Влажность: 75 %
Ветер: 12 км/ч
Давление: 1012 мбар

Рекомендация: лучше надеть куртку!

Хотите узнать погоду в другом городе? да

Введите город: London

Не удалось получить данные о погоде.

Хотите попробовать ещё раз? да

Введите город: Madrid

Город: Madrid
Температура: 24 °C
...

Хотите узнать погоду в другом городе? нет

Программа завершена!
```

### 💡 Подсказки

- Для повторения действий используй `while`.
- Для выхода из цикла можно использовать `break`.
- Обрати внимание: `input()` возвращает строку. Чтобы сравнивать температуру с числами, преобразуй её в `int`.
- Обращение к отсутствующему ключу словаря может вызвать `KeyError`. Запрос к API также может завершиться ошибкой. Подумай, какие действия нужно поместить в `try/except`.
- Для получения температуры используй поле `temp_C` из первого элемента списка `current_condition`.

### ⭐ Дополнительно

Добавь предупреждение о сильном ветре: если скорость ветра превышает 30 км/ч, сообщи пользователю, что на улице ветрено.
