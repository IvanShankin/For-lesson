## 🟢 Электронный дневник

Создай программу для работы с оценками ученика.

Начальный словарь:

```python
student = {
    "name": "Анна",
    "grades": [5, 4, 3, 5]
}
```

### Что должна делать программа:

1. Вывести имя ученика.
2. Вывести все его оценки.
3. Посчитать и вывести средний балл.
4. Пользователь вводит новую оценку.
5. Новая оценка добавляется в список.
6. После добавления снова вывести оценки и средний балл.
7. Если пользователь ввёл не число — программа не должна завершаться с ошибкой.
8. Если оценка меньше `1` или больше `5` — не добавлять её в список.

### Функции

Используй минимум **3 функции**:

* функция для вывода информации об ученике;
* функция для расчёта среднего балла;
* функция для добавления новой оценки.

### 💡 Подсказки

**Подсказка 1.**
Чтобы получить имя из словаря, обратись к ключу `"name"`. Чтобы получить оценки — к ключу `"grades"`.

**Подсказка 2.**
Для расчёта среднего балла тебе понадобятся `sum()` и `len()`.

**Подсказка 3.**
Функция расчёта среднего должна **получить список оценок через аргумент** и вернуть результат через `return`.

**Подсказка 4.**
`input()` возвращает строку. Если пользователь введёт `5`, программа сначала получит `"5"`.

**Подсказка 5.**
Попробуй преобразовать введённое значение в `int`. Именно здесь может возникнуть ошибка, если пользователь напишет, например, `"пять"`.

**Подсказка 6.**
Для обработки такой ситуации используй `try/except`.

**Подсказка 7.**
После получения числа отдельно проверь диапазон: оценка должна быть от `1` до `5`.

**Подсказка 8.**
Если оценка подходит, добавь её в список через `.append()`.

⭐ **Дополнительно:** сделай функцию, которая получает средний балл и возвращает сообщение:

* `4.5–5` → `"Отличный результат!"`
* `3–4.4` → `"Хороший результат!"`
* меньше `3` → `"Нужно подтянуть знания!"`
