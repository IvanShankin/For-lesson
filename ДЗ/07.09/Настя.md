# 🧠 ДЗ: Оценки ученика

Есть список оценок:

```python
grades = [5, 4, 3, 5, 4]
```

Создай программу, которая позволяет работать с оценками.

### Требования:

1. Написать функцию, которая выводит все оценки ученика.
2. Написать функцию, которая получает список оценок и возвращает средний балл.
3. Написать функцию для добавления новой оценки.
4. Пользователь вводит новую оценку через `input()`.
5. Использовать `try/except`, чтобы обработать ввод текста вместо числа.
6. Проверить, что оценка находится от `1` до `5`.
7. Если оценка неправильная — не добавлять её в список.
8. После добавления вывести все оценки и новый средний балл.

💡 **Подсказка:** функции должны выполнять **отдельные задачи**. Не стоит помещать всю программу в одну функцию.

⭐ **Дополнительно:** добавить функцию, которая получает оценку и возвращает сообщение:

* `5` → `"Отлично!"`
* `4` → `"Хорошо!"`
* `3` → `"Нормально"`
* `1–2` → `"Нужно подтянуть знания"`
