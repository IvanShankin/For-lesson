# 🧠 ДЗ: Учёт товаров

Есть словарь с товарами и их количеством:

```python
products = {
    "Хлеб": 10,
    "Молоко": 5,
    "Яблоки": 8
}
```

Программа должна:

1. Написать функцию, которая выводит все товары и их количество.
2. Написать функцию для добавления товара.
3. Пользователь вводит название товара и его количество.
4. Использовать `try/except`, чтобы обработать ситуацию, когда вместо количества введено не число.
5. Если товар уже есть в словаре — увеличить его количество.
6. Если товара нет — добавить его в словарь.
7. После изменения снова вывести все товары.

💡 **Подсказка:** подумай, какие данные должна принимать каждая функция и что она должна делать с ними.

⭐ **Дополнительно:** сделать функцию, которая позволяет удалить товар из словаря. Если такого товара нет — корректно сообщить об этом.
