
# 🟢 Библиотека

Создай программу для небольшой библиотеки.

Есть словарь:

```python
books = {
    "Гарри Поттер": 3,
    "Властелин колец": 2,
    "Маленький принц": 5
}
```

Число рядом с названием — это количество книг.

### Что должна делать программа:

1. Вывести все книги и их количество.
2. Пользователь вводит название книги.
3. Пользователь вводит количество книг, которое хочет взять.
4. Проверить, есть ли такая книга.
5. Проверить, достаточно ли книг в библиотеке.
6. Если всё хорошо — уменьшить количество книг.
7. Если пользователь ввёл вместо количества текст — обработать ошибку через `try/except`.
8. После операции вывести обновлённый список книг.

### Функции

Создай минимум **3 функции**:

* функция вывода всех книг;
* функция проверки/получения информации о книге;
* функция выдачи книги пользователю.

### 💡 Подсказки

**Подсказка 1.**
Для поиска книги в словаре можно проверить, существует ли введённое название среди его ключей.

**Подсказка 2.**
Если книги нет, не пытайся сразу получить её количество из словаря — сначала обработай эту ситуацию.

**Подсказка 3.**
Количество книг пользователь тоже вводит через `input()`, поэтому оно изначально является строкой.

**Подсказка 4.**
Преобразование количества в `int` лучше выполнять внутри `try`, потому что пользователь может написать `"два"`.

**Подсказка 5.**
После получения количества сравни его с количеством книг в словаре.

Например, если есть `3` книги, нельзя выдать `5`.

**Подсказка 6.**
Если книг достаточно, нужно уменьшить их количество на то число, которое взял пользователь.

**Подсказка 7.**
Функция выдачи книги должна получать необходимые данные **через аргументы**, а не самостоятельно запрашивать их через `input()`.

**Подсказка 8.**
Подумай, что функция выдачи книги должна вернуть после успешной операции. Например, новое количество книг.

**Подсказка 9.**
Для вывода всех книг удобно использовать `for`, проходя по словарю.

⭐ **Дополнительно:** если количество книги после выдачи стало `0`, выводить:

`Эта книга закончилась!`
