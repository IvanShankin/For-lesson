
# 🧠 ДЗ: Рефакторинг программы с оценками

Ниже находится программа, которая работает с оценками ученика.

Сейчас весь код написан последовательно, без функций.

### 🟢 Твоя задача

**Отрефактори программу:** раздели её на несколько функций.

Подумай, какие отдельные действия выполняет программа и какие из них логично вынести в функции.

```python
grades = [5, 4, 3, 5, 4, 4, 5]

print("Оценки ученика:")

for grade in grades:
    print(grade)

total = sum(grades)
count = len(grades)
average = total / count

print(f"Всего оценок: {count}")
print(f"Средний балл: {average}")

new_grade = int(input("Введите новую оценку: "))

if 1 <= new_grade <= 5:
    grades.append(new_grade)
    print("Оценка добавлена!")
else:
    print("Ошибка! Оценка должна быть от 1 до 5.")

print("Обновлённые оценки:")

for grade in grades:
    print(grade)
```

---

## 💡 Подсказка

Попробуй выделить отдельные действия:

* вывод оценок;
* расчёт среднего балла;
* добавление новой оценки;
* проверка правильности оценки.

Не обязательно создавать функцию для каждой строки кода.

---

## ⚠️ Важно

После рефакторинга программа должна работать **так же, как раньше**.

Твоя задача не изменить поведение программы, а сделать код более удобным и понятным с помощью функций.
