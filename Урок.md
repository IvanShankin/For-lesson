
### 🟢 Задание 1. Проверка данных ученика

Напиши программу, которая работает с данными ученика.

Создай словарь:

```python
student = {
    "name": "Иван",
    "age": 15,
    "grade": 4
}
```

Программа должна:

1. Написать функцию, которая получает словарь ученика и выводит его имя и возраст.
2. Написать функцию, которая получает оценку и возвращает:

   * `"Отлично"` — если оценка 5
   * `"Хорошо"` — если оценка 4
   * `"Нужно подтянуть знания"` — если оценка 1–3
3. Получить оценку через `input()`.
4. Использовать `try/except`, чтобы программа не завершалась с ошибкой, если вместо числа введён текст.
5. В случае ошибки вывести сообщение:
   **`Ошибка: оценка должна быть числом!`**

💡 **Подсказка:** раздели программу минимум на две функции: одна работает с данными ученика, вторая — с оценкой.

### 🟢 Задание 2. Список покупок

Есть список товаров:

```python
products = ["Хлеб", "Молоко", "Яблоки", "Сыр"]
```

Напиши программу, которая позволяет пользователю узнать цену товара.

Цены храни в отдельном словаре.

Программа должна:

1. Написать функцию, которая получает название товара и словарь с ценами.
2. Функция должна возвращать цену товара.
3. Пользователь вводит название товара.
4. Если такого товара нет в словаре — обработать ошибку через `try/except`.
5. Если товар найден — вывести его цену.
6. Если пользователь вводит пустое название, вывести сообщение об ошибке.
7. В конце программы вывести весь список доступных товаров с помощью цикла.

💡 **Подсказка:** подумай, какая ошибка возникает при попытке получить из словаря ключ, которого в нём нет.

⭐ **Дополнительно:** сделать функцию, которая получает цену и количество товаров и возвращает итоговую стоимость.

### 🟢 Задание 3. Мини-система оценок

Создай программу для работы с оценками ученика.

Есть список:

```python
grades = [5, 4, 3, 5, 4]
```

Программа должна содержать функции:

1. Функция для вывода всех оценок.
2. Функция, которая получает список оценок и возвращает их среднее значение.
3. Функция, которая добавляет новую оценку в список.
4. Пользователь вводит новую оценку через `input()`.
5. Если вместо числа введён текст — обработать это с помощью `try/except`.
6. Если число не находится в диапазоне от 1 до 5 — вывести сообщение об ошибке и не добавлять оценку.
7. После добавления вывести обновлённый список и новый средний балл.

💡 **Подсказка:** не пытайся написать всю программу одной функцией. Подумай, **какая функция за какую отдельную задачу отвечает**.

Здесь хорошо закрепляется сразу почти всё пройденное: **`list`, `dict`, `for`, `if/elif/else`, `input()`, `try/except`, функции, аргументы и `return`**.
