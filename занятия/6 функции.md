# Функции в Python

Функция — это **отдельный блок кода**, который выполняет определённую задачу.
Функцию можно вызвать столько раз, сколько нужно.

---

## 1. Создание функции

Для создания функции используется `def`.

```python
def say_hello():
    print("Привет!")
```

Чтобы выполнить функцию, её нужно вызвать:

```python
say_hello()
```

Результат:

```text
Привет!
```

---

## 2. Аргументы функции

В функцию можно передавать данные.

```python
def say_hello(name):
    print("Привет,", name)

say_hello("Иван")
say_hello("Пётр")
```

Результат:

```text
Привет, Иван
Привет, Пётр
```

`name` — это параметр функции, а `"Иван"` — аргумент, который мы передали.

---

## 3. Возвращение результата — `return`

Функция может не только что-то делать, но и **возвращать результат**.

```python
def add(a, b):
    return a + b

result = add(10, 5)

print(result)
```

Результат:

```text
15
```

`return` возвращает значение из функции.

---

# 4. Аннотации типов

Аннотации типов позволяют указать, **какие данные функция принимает и что возвращает**.

```python
def add(a: int, b: int) -> int:
    return a + b
```

Здесь:

* `a: int` — `a` должно быть целым числом
* `b: int` — `b` должно быть целым числом
* `-> int` — функция возвращает целое число

Ещё пример:

```python
def greet(name: str) -> str:
    return "Привет, " + name
```

`name: str` — функция принимает строку.
`-> str` — функция возвращает строку.

---

## 📌 Главное запомнить

* `def` — создание функции
* Функция позволяет **не повторять один и тот же код**
* Параметры позволяют передавать данные в функцию
* `return` возвращает результат
* `: int`, `: str` и другие аннотации показывают тип данных
* `-> int`, `-> str` показывают тип возвращаемого значения

```python
def multiply(a: int, b: int) -> int:
    return a * b

result = multiply(5, 3)

print(result)
```

Результат:

```text
15
```
