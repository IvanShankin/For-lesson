# 📄 Работа с файлами в Python

Часто программы должны сохранять данные или читать их из существующих файлов. Для этого в Python есть встроенная функция `open()`.

---

## 1. Открытие файла

Чтобы начать работать с файлом, его нужно открыть, передав имя файла и **режим работы** (чтение, запись и т.д.). 
Для работы с русскими буквами **обязательно** указывайте параметр `encoding="utf-8"`.

| Режим | Для чего нужен |
|---|---|
| `"r"` | Чтение (read). Открывает файл только для чтения (по умолчанию). |
| `"w"` | Запись (write). Создает новый файл или **стирает** старый. |
| `"a"` | Добавление (append). Добавляет текст в **конец** файла, не удаляя старый. |

---

## 2. Запись в файл (режим "w" и "a")

Метод `write()` записывает текст в файл.

```python
# Открываем файл для записи (создастся новый или очистится старый)
file = open("my_file.txt", "w", encoding="utf-8")

file.write("Привет, мир!\n")
file.write("Это вторая строка.")

# Обязательно закрываем файл после работы!
file.close()
```

⚠️ Символ `\n` означает перенос на новую строку.

---

## 3. Чтение из файла (режим "r")

Метод `read()` читает всё содержимое файла целиком.

```python
file = open("my_file.txt", "r", encoding="utf-8")

text = file.read()
print(text)

file.close()
```

Результат:
```
Привет, мир!
Это вторая строка.
```

Если нужно прочитать файл построчно (особенно полезно для больших файлов), можно использовать цикл `for`:

```python
file = open("my_file.txt", "r", encoding="utf-8")

for line in file:
    print(line.strip()) # strip() убирает лишние невидимые символы (включая перенос строки \n в конце)
    
file.close()
```

---

## 📌 Что нужно запомнить

* Функция `open()` открывает файл.
* `encoding="utf-8"` — **обязательный параметр** для правильной записи и чтения русского текста.
* Режимы: `"r"` (чтение), `"w"` (запись с заменой), `"a"` (добавление в конец).
* Метод `write()` пишет в файл, `read()` читает из него.
* Файлы **обязательно нужно закрывать** методом `close()`, чтобы данные сохранились на диск и программа не занимала лишнюю память.
