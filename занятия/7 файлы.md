# Работа с файлами в Python

Python позволяет создавать, читать и изменять файлы.

Для работы с файлом используется функция `open()`.

## 1. Открытие файла

``` python
file = open("example.txt", "r")
```

Здесь:

-   `"example.txt"` --- имя файла;
-   `"r"` --- режим работы с файлом.

Основные режимы:

  Режим   Значение
  ------- --------------------------
  `"r"`   чтение
  `"w"`   запись
  `"a"`   добавление в конец файла

Обычно файл используют вместе с `with`:

``` python
with open("example.txt", "r") as file:
    # работа с файлом
```

## 2. Чтение файла

Метод `read()` считывает всё содержимое файла.

``` python
with open("example.txt", "r") as file:
    text = file.read()

print(text)
```

## 3. Чтение строк

Метод `readline()` читает одну строку:

``` python
with open("example.txt", "r") as file:
    line = file.readline()

print(line)
```

Метод `readlines()` возвращает строки файла в виде списка:

``` python
with open("example.txt", "r") as file:
    lines = file.readlines()

print(lines)
```

## 4. Запись в файл

Режим `"w"` позволяет записывать данные в файл.

``` python
with open("example.txt", "w") as file:
    file.write("Привет, Python!")
```

⚠️ Режим `"w"` перезаписывает содержимое файла.

## 5. Добавление в файл

Режим `"a"` добавляет данные в конец файла.

``` python
with open("example.txt", "a") as file:
    file.write("\nНовая строка")
```

Старое содержимое при этом сохраняется.

## 6. Чтение и запись

Можно использовать разные режимы в зависимости от задачи:

``` python
# Прочитать
with open("example.txt", "r") as file:
    print(file.read())

# Перезаписать
with open("example.txt", "w") as file:
    file.write("Новый текст")

# Добавить
with open("example.txt", "a") as file:
    file.write("\nЕщё один текст")
```

## 7. Главное запомнить

-   `open()` --- открывает файл.
-   `"r"` --- чтение.
-   `"w"` --- запись с перезаписью.
-   `"a"` --- добавление в конец.
-   `read()` --- прочитать всё содержимое.
-   `readline()` --- прочитать одну строку.
-   `readlines()` --- получить строки в виде списка.
-   `write()` --- записать текст.
-   `with` автоматически закрывает файл после работы с ним.

### Самый частый вариант

``` python
with open("example.txt", "r") as file:
    text = file.read()

print(text)
```
