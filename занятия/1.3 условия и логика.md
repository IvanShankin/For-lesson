# Краткая памятка по Python: Условия и логика

## 1. Сравнение значений

Для того чтобы сравнивать переменные и значения, используются специальные операторы.

| Оператор | Значение         |
| -------- | ---------------- |
| `==`     | равно            |
| `!=`     | не равно         |
| `>`      | больше           |
| `<`      | меньше           |
| `>=`     | больше или равно |
| `<=`     | меньше или равно |

Пример:

```python
age = 15
print(age >= 12) # Вернёт True
```

---

## 2. Условные операторы

Позволяют выполнять разный код в зависимости от условия.

### if (Если)

```python
age = 18

if age >= 18:
    print("Вы совершеннолетний")
```

### if - else (Если - Иначе)

```python
age = 15

if age >= 18:
    print("Вы совершеннолетний")
else:
    print("Вы несовершеннолетний")
```

### if - elif - else (Несколько условий)

`elif` — это сокращение от else if (иначе если).

```python
score = 75

if score >= 90:
    print("Отлично")
elif score >= 70:
    print("Хорошо")
else:
    print("Нужно подтянуть знания")
```

## 3. Логические операторы `and` и `or`

Иногда нужно проверять сразу несколько условий.

### `and` (И)

Условие будет истинным, только если **все проверки истинны**.

```python
age = 20
has_passport = True

if age >= 18 and has_passport:
    print("Можно путешествовать")
```

### `or` (ИЛИ)

Условие будет истинным, если **хотя бы одна проверка истинна**.

```python
day = "суббота"

if day == "суббота" or day == "воскресенье":
    print("Сегодня выходной")
```

## 4. Пример простой программы с условиями

```python
name = input("Введите имя: ")
age = int(input("Введите возраст: "))

if age >= 18:
    print(name, "— вы совершеннолетний!")
else:
    print(name, "— вы еще несовершеннолетний.")
```

---

## Что нужно запомнить

* `if`, `elif`, `else` — позволяют вашей программе принимать решения в зависимости от условий.
* Каждое условие должно завершаться двоеточием `:`.
* Внутри условия обязателен отступ (обычно 4 пробела или Tab).
* `and` требует выполнения **всех** условий.
* `or` требует выполнения **хотя бы одного** условия.
