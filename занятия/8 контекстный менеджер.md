# 🛡️ Контекстный менеджер (with)

При обычной работе с файлами с помощью `open()` и `close()`, есть риск забыть закрыть файл. Или же в программе может произойти ошибка до вызова `close()`, и тогда файл останется открытым.

Чтобы избежать этих проблем, в Python используют **контекстные менеджеры** с помощью конструкции `with`.

---

## 1. Как работает конструкция with

Конструкция `with` берет на себя рутину: она автоматически закроет файл, как только код внутри её блока завершит работу. Вам **больше не нужно** писать `file.close()`.

### Пример записи:

```python
# Файл закроется сам, как только закончатся отступы
with open("notes.txt", "w", encoding="utf-8") as file:
    file.write("Первая запись через with.\n")
    file.write("Файл будет закрыт автоматически!")

# Здесь код без отступа — значит файл уже надежно закрыт
```

### Пример чтения:

```python
with open("notes.txt", "r", encoding="utf-8") as file:
    content = file.read()
    print(content)
```

Результат:
```
Первая запись через with.
Файл будет закрыт автоматически!
```

---

## 2. Чтение файла построчно через with

Это самый правильный и частый способ чтения файлов в Python:

```python
with open("notes.txt", "r", encoding="utf-8") as file:
    for line in file:
        print(line.strip()) # strip() удаляет лишние пробелы и переносы строк по краям
```

---

## 📌 Главное про with

* Конструкция `with` создает безопасный блок кода ("контекст").
* Файл, открытый через `with open(...) as ...`, **закрывается автоматически**.
* Гарантирует закрытие файла, даже если внутри блока произойдет критическая ошибка.
* Это стандарт и самая хорошая практика в Python. Приучите себя всегда использовать `with` вместо ручного вызова `close()`!
