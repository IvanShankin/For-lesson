# Контекстный менеджер в Python

Контекстный менеджер помогает правильно выполнить какое-то действие и
автоматически завершить его после выхода из блока кода.

Для работы с контекстным менеджером используется конструкция `with`.

## 1. Конструкция `with`

Общий вид:

``` python
with что-то:
    # код внутри блока
```

Код с отступом после `with` выполняется внутри контекстного менеджера.

Например:

``` python
with open("example.txt", "r") as file:
    print(file.read())
```

Здесь `with` открывает файл, позволяет работать с ним внутри блока, а
после завершения блока файл автоматически закрывается.

## 2. Почему используется `with`

Без `with` файл пришлось бы закрывать самостоятельно:

``` python
file = open("example.txt", "r")

print(file.read())

file.close()
```

С `with` закрытие происходит автоматически:

``` python
with open("example.txt", "r") as file:
    print(file.read())
```

Поэтому `with` удобен и помогает не забывать закрывать ресурсы.

## 3. Что важно запомнить

-   `with` используется для работы с контекстным менеджером.
-   Код внутри `with` пишется с отступом.
-   После выхода из блока `with` нужное действие завершается
    автоматически.
-   Один из самых частых примеров использования `with` --- работа с
    файлами.

### Главное правило

``` python
with что-то:
    # работаем с чем-то
```
