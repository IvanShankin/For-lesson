### Цикл `while`

Цикл `while` выполняется до тех пор, пока условие остается истинным (`True`).

```python
number = 1

while number <= 5:
    print(number)
    number = number + 1
```

Результат:

```text
1
2
3
4
5
```

Пока выполняется условие `number <= 5`, цикл будет повторяться.

⚠️ Важно изменять переменные внутри цикла. Иначе цикл может стать бесконечным.

Пример бесконечного цикла:

```python
while True:
    print("Это бесконечный цикл!")
```

---

### Когда используют `while`

Например, когда нужно запрашивать данные у пользователя, пока он не введет правильное значение:

```python
password = ""

while password != "1234":
    password = input("Введите пароль: ")

print("Доступ разрешён!")
```

Цикл будет работать до тех пор, пока пользователь не введёт пароль `1234`.


### Оператор `break`

`break` позволяет **прервать цикл досрочно**, не дожидаясь, пока условие станет ложным.

```python
number = 1

while True:
    print(number)

    if number == 5:
        break

    number += 1
```

Результат:

```text
1
2
3
4
5
```

Когда `number` становится равным `5`, выполняется `break`, и цикл сразу завершается.

⚠️ `break` работает только внутри циклов (`while` и `for`).

---

### Оператор `continue`

`continue` позволяет **пропустить оставшуюся часть текущей итерации** и перейти к следующей.

```python
number = 0

while number < 5:
    number += 1
    
    if number == 3:
        continue
    
    print(number)
```

Результат:

```text
1
2
4
5
```

Когда `number` становится равным `3`, выполняется `continue`, и код после него (`print(number)`) пропускается. Цикл переходит к следующей итерации.

```python
# Пример: выводим только нечетные числа
num = 0

while num < 10:
    num += 1
    
    if num % 2 == 0:  # если число четное
        continue       # пропускаем вывод
    
    print(num)         # выводятся только нечетные числа
```

Результат:

```text
1
3
5
7
9
```

⚠️ `continue` работает только внутри циклов (`while` и `for`).

**Отличие от `break`:**  
- `break` — полностью завершает цикл  
- `continue` — пропускает только текущий шаг, цикл продолжается

## Цикл for

Цикл `for` используется, когда нужно пройтись по **набору данных** (например: список, строки, числа).

---

### 🔹 Пример с числами (range)

```python
for i in range(5):
    print(i)
```

Результат:

```
0
1
2
3
4
```

---

### 🔹 Можно перебирать список

Список — это набор значений.

```python
numbers = [10, 20, 30, 40]

for num in numbers:
    print(num)
```

Результат:

```
10
20
30
40
```

👉 Здесь цикл проходит по каждому элементу списка.

---

### 🔹 Можно перебирать строки (текст)

```python
word = "Python"

for letter in word:
    print(letter)
```

Результат:

```
P
y
t
h
o
n
```

👉 Строка — это тоже набор символов.

---

### 🔹 for + break

`break` останавливает цикл раньше времени.

```python
numbers = [1, 2, 3, 4, 5]

for num in numbers:
    if num == 3:
        break
    print(num)
```

Результат:

```
1
2
```

---

### 🔹 for + continue

`continue` пропускает текущую итерацию.

```python
numbers = [1, 2, 3, 4, 5]

for num in numbers:
    if num == 3:
        continue
    print(num)
```

Результат:

```
1
2
4
5
```

👉 Число `3` пропущено, но цикл продолжился дальше.

---

## 📌 Главное запомнить

* `for` нужен для перебора данных
* можно перебирать:
  * числа (`range`)
  * списки (`list`)
  * строки (`str`)
* цикл идёт по каждому элементу по очереди
* `break` — останавливает цикл полностью
* `continue` — пропускает только текущий шаг, цикл продолжается
