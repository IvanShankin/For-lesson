# Обработка ошибок в Python

Иногда в программе возникают ошибки. Чтобы программа не завершалась с ошибкой, используют `try` и `except`.

---

# 🛡️ Конструкция `try...except`

Код внутри `try` выполняется первым.

Если возникает ошибка, выполняется код внутри `except`.

### Пример

```python
person = {
    "name": "Иван",
    "age": 20
}

try:
    print(person["city"])
except:
    print("Такого ключа нет!")
```

Результат:

```text
Такого ключа нет!
```

В словаре нет ключа `"city"`, поэтому программа переходит в `except` и не завершается с ошибкой.

---

### Можно обрабатывать определённую ошибку

Лучше указывать, какую именно ошибку мы ожидаем.

```python
person = {
    "name": "Иван"
}

try:
    print(person["city"])
except KeyError:
    print("Ключ не найден!")
```

---

# 🚨 Оператор `raise`

`raise` позволяет **самостоятельно вызвать ошибку**.

Это полезно, если данные не подходят под наши условия.

### Пример

```python
person = {
    "name": "Иван"
}

if "age" not in person:
    raise KeyError("Возраст не указан!")
```

Результат:

```text
KeyError: Возраст не указан!
```

Программа сама создаст ошибку, если ключ `"age"` отсутствует.

---

## 📌 Главное запомнить

* `try` — код, который может вызвать ошибку.
* `except` — код, который выполнится, если ошибка произошла.
* `raise` — позволяет самостоятельно вызвать ошибку.
