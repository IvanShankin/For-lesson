# Краткая памятка по Python: Переменные и типы данных

## 1. Переменные

Переменная — это имя, под которым хранится значение.

```python
name = "Иван"
age = 15
height = 1.75
```

Вывод значения:

```python
print(name)
print(age)
```

---

## 2. Типы данных

### Целые числа (int)

```python
age = 15
score = 100
```

### Дробные числа (float)

```python
price = 99.99
height = 1.75
```

### Строки (str)

Текст записывается в кавычках.

```python
name = "Иван"
city = 'Москва'
```

### Логический тип (bool)

Может иметь только два значения:

```python
is_student = True
is_adult = False
```

---

## Что нужно запомнить

* `int` — целые числа (`10`, `25`, `-7`)
* `float` — дробные числа (`3.14`, `1.5`)
* `str` — текст (`"Привет"`)
* `bool` — `True` или `False`
* Переменная хранит значение:

```python
name = "Иван"
age = 15
```

Python читает код сверху вниз и выполняет команды по порядку. 🚀
