# 📥 1. Функция input()

Используется для получения данных от пользователя.

```python
name = input("Введите имя: ")
print("Привет,", name)
```

Всегда возвращает строку. Для чисел нужно преобразовывать:

```python
age = int(input("Введите возраст: "))
```

---

# 📤 2. Функция print()

Используется для вывода информации на экран.

```python
name = "Иван"
age = 15
print("Имя:", name)
print("Возраст:", age)
```

Вывод в консоль:

```
Имя: Иван
Возраст: 15
```

---

# 📏 3. Функция len()

Возвращает количество элементов в строке, списке или другой коллекции.

```python
word = "Python"
print(len(word)) # Вывод: 6

numbers = [10, 20, 30, 40]
print(len(numbers)) # Вывод: 4
```

---

# ➕ 4. Функция sum()

Возвращает сумму всех чисел в списке.

```python
numbers = [10, 20, 30]
print(sum(numbers)) # Вывод: 60
```

---

# 🔎 5. Функция type()

Возвращает тип переданного значения или переменной. Очень полезна при поиске ошибок!

```python
print(type("Привет")) # Вывод: <class 'str'>
print(type(10))       # Вывод: <class 'int'>
print(type(3.14))     # Вывод: <class 'float'>
print(type(True))     # Вывод: <class 'bool'>
print(type([1, 2]))   # Вывод: <class 'list'>
```

---

# ⬆️⬇️ 6. Функции max() и min()

Находят самое большое (`max`) и самое маленькое (`min`) значение среди переданных аргументов или внутри списка.

```python
numbers = [5, 2, 9, 1, 7]
print(max(numbers)) # Вывод: 9
print(min(numbers)) # Вывод: 1

# Можно передавать значения напрямую
print(max(10, 50, 30)) # Вывод: 50
```

---

# 🔢 7. Функция range()

Создает последовательность чисел. Часто используется вместе с циклами `for`.

```python
# От 0 до 4
print(list(range(5))) # Вывод: [0, 1, 2, 3, 4]

# От 2 до 5
print(list(range(2, 6))) # Вывод: [2, 3, 4, 5]

# От 1 до 9 с шагом 2
print(list(range(1, 10, 2))) # Вывод: [1, 3, 5, 7, 9]
```

---

# 🔄 8. Функция round()

Округляет дробное число.

```python
num = 3.14159

# Округление до целого
print(round(num)) # Вывод: 3

# Округление до двух знаков после запятой
print(round(num, 2)) # Вывод: 3.14
```

---

# 📊 9. Функция sorted()

Возвращает новый, отсортированный список из переданной коллекции.

```python
numbers = [5, 2, 9, 1, 7]
sorted_numbers = sorted(numbers)

print(sorted_numbers) # Вывод: [1, 2, 5, 7, 9]
print(numbers) # Заметьте, что исходный список не изменился!

# Сортировка по убыванию
print(sorted(numbers, reverse=True)) # Вывод: [9, 7, 5, 2, 1]
```

# 📝 Кратко

| Функция | Что делает |
|---------|------------|
| `input()` | Получает данные от пользователя (текст) |
| `print()` | Выводит данные на экран |
| `len()` | Считает количество элементов (длину) |
| `sum()` | Суммирует числа в списке |
| `type()` | Узнает тип данных переменной или значения |
| `max()` | Находит максимальное значение |
| `min()` | Находит минимальное значение |
| `range()` | Создает последовательность чисел |
| `round()` | Округляет дробные числа |
| `sorted()`| Сортирует список (от меньшего к большему) |
