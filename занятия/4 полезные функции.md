
# 📥 1. Функция input()

Используется для получения данных от пользователя.

```python
name = input("Введите имя: ")
print("Привет,", name)
```

Всегда возвращает строку. Для чисел нужно преобразовывать:

```python
age = int(input("Введите возраст: "))
```

---

# 📤 2. Функция print()

Используется для вывода информации на экран.

```python
print("Привет!")
print(10)
print(True)
```

Можно выводить несколько значений:

```python
name = "Иван"
age = 15

print("Имя:", name)
print("Возраст:", age)
```

Вывод в консоль:

```
Имя: Иван
Возраст: 15
```

---

# 📏 3. Функция len()

Возвращает количество элементов в строке, списке или другой коллекции.

```python
word = "Python"
print(len(word))
```

Вывод:

```
6
```

Со списком:

```python
numbers = [10, 20, 30, 40]
print(len(numbers))
```

Вывод:

```
4
```

---

# ➕ 4. Функция sum()

Возвращает сумму всех чисел в списке.

```python
numbers = [10, 20, 30]
print(sum(numbers))
```

Вывод:

```
60
```

---

# 📝 Кратко

| Функция | Что делает |
|---------|------------|
| `input()` | Получает данные от пользователя |
| `print()` | Выводит данные на экран |
| `len()` | Считает количество элементов |
| `sum()` | Суммирует числа в списке |
