# 🌐 Общение с API в Python (библиотека requests)

Когда программе нужны внешние данные (например, курс валют, прогноз погоды или новости), она обращается к **API** (Application Programming Interface).

API — это интерфейс прикладного программирования, набор правил, по которым одна программа может общаться с другой через интернет.

---

## 1. Как работает клиент-серверное общение

1. **Клиент** (наша программа на Python) отправляет **запрос** (Request) на сервер по ссылке (URL).
2. **Сервер** обрабатывает запрос и присылает **ответ** (Response), в котором содержатся статус и нужные данные.

Самый распространённый тип запроса — **GET-запрос** (запрос на получение данных).

---

## 2. Библиотека requests

Для отправки сетевых запросов в Python используется популярная сторонняя библиотека `requests`.

### Установка (если ещё не установлена)
В терминале:
```bash
pip install requests
```

### Подключение в программе
```python
import requests
```

---

## 3. Отправка GET-запроса и проверка статуса

Чтобы отправить запрос, вызывается функция `requests.get()`:

```python
import requests

url = "https://wttr.in/Moscow?format=j1"
response = requests.get(url)

# Код статуса ответа: 200 означает «Успешно» (OK)
print("Статус-код:", response.status_code)
```

| Код ответа | Значение | Что делать |
|---|---|---|
| `200` | OK (успешно) | Всё отлично, можно извлекать данные |
| `404` | Not Found (не найдено) | Проверьте адрес или введённый город |
| `500` / `502` | Server Error | Ошибка на сервере, запрос не удался |

---

## 4. Формат JSON и метод `.json()`

Большинство современных API возвращают данные в текстовом формате **JSON** (JavaScript Object Notation). 
В Python он практически один в один повторяет словари (`dict`) и списки (`list`).

Метод `.json()` у ответа автоматически парсит текст и превращает его в структуры данных Python:

```python
data = response.json()
print(type(data))  # <class 'dict'>
```

## 5. Работа с погодным сервисом `wttr.in`

Сервис `wttr.in` умеет возвращать подробную погоду для любого города.

Чтобы получить данные в формате JSON, в конце ссылки обязательно указывается параметр `?format=j1`:

```python
city = "Helsinki"
url = f"https://wttr.in/{city}?format=j1"

response = requests.get(url)
data = response.json()
```

### Структура ответа `wttr.in`

Словарь `data` содержит следующие основные ключи:

```text
data
├── 'current_condition' -> [ {...} ]  (список с текущей погодой, берем [0])
│    ├── 'temp_C'            # Текущая температура (°C)
│    ├── 'FeelsLikeC'        # Ощущаемая температура (°C)
│    ├── 'humidity'          # Влажность воздуха (%)
│    ├── 'windspeedKmph'     # Скорость ветра (км/ч)
│    └── 'pressure'          # Атмосферное давление (мбар / гПа)
│
└── 'weather' -> [ {...}, {...}, {...} ]  (список прогнозов по дням: [0] — сегодня)
     ├── 'mintempC'          # Минимальная температура за сегодня (°C)
     ├── 'maxtempC'          # Максимальная температура за сегодня (°C)
     └── 'date'              # Дата прогноза
```

---

### Получение текущей погоды (`current_condition`)

Текущее состояние погоды хранится в первом элементе списка под ключом `current_condition`:

```python
current = data["current_condition"][0]

temp = current["temp_C"]               # Температура
feels_like = current["FeelsLikeC"]      # Ощущается как
humidity = current["humidity"]          # Влажность (%)
wind = current["windspeedKmph"]         # Ветер (км/ч)
pressure = current["pressure"]          # Давление (мбар / гПа)

print(f"Температура: {temp} °C")
print(f"Ощущается как: {feels_like} °C")
print(f"Влажность: {humidity} %")
print(f"Ветер: {wind} км/ч")
print(f"Давление: {pressure} мбар")
```

---

### Получение прогноза на сегодня (`weather`)

Данные о погоде на сегодня находятся в первом элементе списка под ключом `weather`:

```python
today = data["weather"][0]

min_temp = today["mintempC"]  # Минимальная температура за сегодня
max_temp = today["maxtempC"]  # Максимальная температура за сегодня

print(f"Минимальная температура сегодня: {min_temp} °C")
print(f"Максимальная температура сегодня: {max_temp} °C")
```

## 6. Важные приёмы для выполнения ДЗ 💡

### 1. Преобразование строковых значений в числа
> [!IMPORTANT]
> Все числовые значения из `wttr.in` приходят в виде **строк** (`str`), например: `'8'`, `'75'`, `'12'`.  
> Чтобы сравнивать их с числами в блоках `if / elif / else`, их обязательно нужно преобразовать функцией `int()`!

```python
temp = int(current["temp_C"])
feels = int(current["FeelsLikeC"])
wind = int(current["windspeedKmph"])
humidity = int(current["humidity"])

# Теперь можно сравнивать:
if temp < 0:
    print("Холодно, возьми тёплую одежду!")
elif 0 <= temp <= 10:
    print("Не забудь куртку!")
else:
    print("Погода комфортная!")

# Проверка сильного ветра:
if wind > 30:
    print("Внимание: на улице сильный ветер!")

# Проверка высокой влажности:
if humidity > 80:
    print("Внимание: высокая влажность!")
```

### 2. Безопасность и обработка ошибок (`try / except`)
При работе с сетью и внешними API всегда возможны непредвиденные ситуации:
- пользователь ввёл несуществующий город или допустил опечатку;
- сервер временно недоступен или отключился интернет;
- ответ пришёл не в том формате, и ключ в словаре отсутствует (`KeyError`).

Чтобы программа не падала с красной ошибкой, оборачивайте сетевой запрос и разбор данных в блок `try...except`:

```python
try:
    url = f"https://wttr.in/{city}?format=j1"
    response = requests.get(url)
    
    # Проверяем успешность ответа
    if response.status_code != 200:
        print("Не удалось получить данные о погоде.")
    else:
        data = response.json()
        current = data["current_condition"][0]
        # Извлекаем и выводим информацию...
except requests.exceptions.RequestException:
    print("Ошибка соединения с сетью. Проверьте интернет!")
except (KeyError, IndexError):
    print("Не удалось распознать город или данные повреждены.")
except Exception as e:
    print("Произошла ошибка при получении данных.")
```

### 3. Цикл `while` для многократных запросов
Чтобы пользователь мог проверить несколько городов подряд и сам решить, когда остановиться, используем цикл `while True` с выходом по условию через `break`:

```python
while True:
    city = input("\nВведите город: ").strip()
    
    # Получение и вывод погоды...
    
    # Спрашиваем пользователя о продолжении
    again = input("\nХотите проверить другой город? (да/нет): ").strip().lower()
    if again != "да":
        print("Программа завершена!")
        break
```

## 📌 Шпаргалка / Главное запомнить

* `requests.get(url)` — выполняет сетевой GET-запрос.
* `response.status_code` — числовой код ответа (200 = успешно).
* `response.json()` — конвертирует ответ в словарь / список Python.
* `f"https://wttr.in/{city}?format=j1"` — ссылка на API `wttr.in` для получения данных в JSON.
* Поля в словаре `current_condition[0]`:
  - `temp_C` — температура в градусах Цельсия
  - `FeelsLikeC` — ощущаемая температура
  - `humidity` — влажность воздуха в %
  - `windspeedKmph` — скорость ветра в км/ч
  - `pressure` — давление в мбар/гПа
* Поля в словаре `weather[0]`:
  - `mintempC` — минимальная температура на сегодня
  - `maxtempC` — максимальная температура на сегодня
* Данные из API приходят строками — используйте `int(...)` перед сравнениями с числами.
* Оборачивайте работу с API в `try...except`, чтобы программа работала стабильно.
