# Структуры данных в Python

Структуры данных нужны для хранения нескольких значений в одной переменной.

---

# 🔒 Tuple (кортеж)

Кортеж похож на список, но его нельзя изменять после создания.

```python
numbers = (10, 20, 30)

print(numbers)
```

Результат:

```python
(10, 20, 30)
```

---

### Получить элемент по индексу

```python
numbers = (10, 20, 30)

print(numbers[1])
```

Результат:

```python
20
```

---

### Узнать количество элементов

```python
numbers = (10, 20, 30)

print(len(numbers))
```

Результат:

```python
3
```

---

### Что нельзя делать

```python
numbers = (10, 20, 30)

numbers.append(40)
```

Результат:

```python
Ошибка!
```

Кортеж нельзя изменять.

---

## 📌 Главное про tuple

* Хранит данные по порядку
* Имеет индексы
* Нельзя изменять после создания
* Часто используется для постоянных данных
