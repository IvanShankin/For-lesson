# Структуры данных в Python

Структуры данных нужны для хранения нескольких значений в одной переменной.

---

# 🔒 Tuple (кортеж)

Кортеж похож на список, но его **нельзя изменять** после создания.

```python
numbers = (10, 20, 30)

print(numbers)
```

Результат:

```python
(10, 20, 30)
```

---

### Получить элемент по индексу

```python
numbers = (10, 20, 30)

print(numbers[1])
```

Результат:

```python
20
```

---

### Узнать количество элементов — len()

```python
numbers = (10, 20, 30)

print(len(numbers))
```

Результат:

```python
3
```

---

### Посчитать количество совпадений — count()

Как и в списке, можно посчитать, сколько раз элемент встречается в кортеже.

```python
numbers = (10, 20, 10, 30, 10)
print(numbers.count(10))
```

Результат:
```python
3
```

---

### Найти индекс элемента — index()

Возвращает индекс первого найденного элемента.

```python
numbers = (10, 20, 30)
print(numbers.index(20))
```

Результат:
```python
1
```

---

### Что нельзя делать

```python
numbers = (10, 20, 30)

numbers.append(40)  # Ошибка!
numbers[0] = 100    # Ошибка!
```

Результат:

```python
Ошибка!
```

Кортеж нельзя изменять.

---

## 📌 Главное про tuple

* Хранит данные по порядку
* Элементы имеют индексы (начинаются с `0`)
* Нельзя изменять после создания (immutable)
* Работает быстрее списка и занимает меньше памяти
* Часто используется для постоянных данных (например, координаты точек)
