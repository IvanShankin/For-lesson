# Структуры данных в Python

Структуры данных нужны для хранения нескольких значений в одной переменной.

---

# 🎲 Set (множество)

Множество хранит только уникальные значения. Порядок элементов не сохраняется.

```python
numbers = {1, 2, 3, 3, 3}

print(numbers)
```

Результат:

```python
{1, 2, 3}
```

Повторы автоматически удаляются.

---

### Добавить элемент — add()

```python
numbers = {1, 2, 3}

numbers.add(4)

print(numbers)
```

Результат:

```python
{1, 2, 3, 4}
```

---

### Удалить элемент — remove() и discard()

`remove()` удаляет элемент, но если его нет — выдает ошибку.
`discard()` удаляет элемент, и если его нет — ничего не делает (ошибки не будет).

```python
numbers = {1, 2, 3}

numbers.remove(2)
numbers.discard(5) # Ошибки не будет

print(numbers)
```

Результат:

```python
{1, 3}
```

---

### Очистить множество — clear()

```python
numbers = {1, 2, 3}
numbers.clear()
print(numbers)
```

Результат:
```python
set()
```

---

### Объединение множеств — union() или |

Создает новое множество, объединяя уникальные элементы из всех множеств.

```python
set1 = {1, 2, 3}
set2 = {3, 4, 5}

print(set1.union(set2))
# или так: print(set1 | set2)
```

Результат:
```python
{1, 2, 3, 4, 5}
```

---

### Пересечение множеств — intersection() или &

Оставляет только те элементы, которые есть и в первом, и во втором множестве.

```python
set1 = {1, 2, 3}
set2 = {3, 4, 5}

print(set1.intersection(set2))
# или так: print(set1 & set2)
```

Результат:
```python
{3}
```

---

### Разность множеств — difference() или -

Оставляет элементы из первого множества, которых нет во втором.

```python
set1 = {1, 2, 3, 4}
set2 = {3, 4, 5}

print(set1.difference(set2))
# или так: print(set1 - set2)
```

Результат:
```python
{1, 2}
```

---

### Проверить наличие элемента

```python
numbers = {1, 2, 3}

print(2 in numbers)
```

Результат:

```python
True
```

---

## 📌 Главное про set

* Хранит только уникальные значения
* Порядок элементов не гарантируется
* Повторы автоматически удаляются
* Можно использовать математические операции с множествами (объединение, пересечение, разность)
* Очень быстро работает проверка на наличие элемента (`in`)
