# Структуры данных в Python

Структуры данных нужны для хранения нескольких значений в одной переменной.

---


# 🎲 Set (множество)

Множество хранит только уникальные значения.

```python
numbers = {1, 2, 3, 3, 3}

print(numbers)
```

Результат:

```python
{1, 2, 3}
```

Повторы автоматически удаляются.

---

### Добавить элемент — add()

```python
numbers = {1, 2, 3}

numbers.add(4)

print(numbers)
```

Результат:

```python
{1, 2, 3, 4}
```

---

### Удалить элемент — remove()

```python
numbers = {1, 2, 3}

numbers.remove(2)

print(numbers)
```

Результат:

```python
{1, 3}
```

---

### Проверить наличие элемента

```python
numbers = {1, 2, 3}

print(2 in numbers)
```

Результат:

```python
True
```

---

## 📌 Главное про set

* Хранит только уникальные значения
* Порядок элементов не гарантируется
* Повторы автоматически удаляются
* Удобно для проверки наличия элемента
