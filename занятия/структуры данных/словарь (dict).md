# Структуры данных в Python

Структуры данных нужны для хранения нескольких значений в одной переменной.

---

# 📖 Dict (словарь)

Словарь хранит данные в формате **ключ : значение**.

```python
person = {
    "name": "Иван",
    "age": 20
}

print(person)
```

Результат:

```python
{'name': 'Иван', 'age': 20}
```

---

### Получить значение по ключу

```python
person = {
    "name": "Иван",
    "age": 20
}

print(person["name"])

# Метод, который не вызывает ошибку, если ключа нет -> вернет None
print(person.get("name")) 
```

Результат:

```python
Иван
Иван
```

---

### Добавить новый ключ или изменить существующий

```python
person = {
    "name": "Иван"
}

person["age"] = 20 # добавление
person["name"] = "Петр" # изменение

print(person)
```

Результат:

```python
{'name': 'Петр', 'age': 20}
```

---

### Обновить словарь новыми данными — update()

Добавляет пары ключ-значение из другого словаря.

```python
person = {"name": "Иван"}
person.update({"age": 20, "city": "Москва"})

print(person)
```

Результат:
```python
{'name': 'Иван', 'age': 20, 'city': 'Москва'}
```

---

### Удалить ключ — pop()

Удаляет указанный ключ и возвращает его значение.

```python
person = {
    "name": "Иван",
    "age": 20
}

age = person.pop("age")

print(person)
```

Результат:

```python
{'name': 'Иван'}
```

---

### Получить все ключи — keys()

```python
person = {
    "name": "Иван",
    "age": 20
}

print(person.keys())
```

Результат:

```python
dict_keys(['name', 'age'])
```

---

### Получить все значения — values()

```python
person = {
    "name": "Иван",
    "age": 20
}

print(person.values())
```

Результат:

```python
dict_values(['Иван', 20])
```

---

### Получить все пары ключ-значение — items()

Удобно использовать в циклах `for`.

```python
person = {
    "name": "Иван",
    "age": 20
}

print(person.items())
```

Результат:

```python
dict_items([('name', 'Иван'), ('age', 20)])
```

---

### Очистить словарь — clear()

Удаляет все элементы из словаря.

```python
person = {"name": "Иван"}
person.clear()

print(person)
```

Результат:
```python
{}
```

---

## 📌 Главное про dict (словарь)

* Хранит данные в формате **ключ : значение**
* Получение данных происходит по ключу (`person["name"]` или `person.get("name")`)
* Можно добавлять, изменять и удалять значения
* Каждый ключ должен быть уникальным
* Ключами могут быть только неизменяемые типы (строки, числа, кортежи)
