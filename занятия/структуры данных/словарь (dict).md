# Структуры данных в Python

Структуры данных нужны для хранения нескольких значений в одной переменной.

---


# 📖 Dict (словарь)

Словарь хранит данные в формате **ключ : значение**.

```python
person = {
    "name": "Иван",
    "age": 20
}

print(person)
```

Результат:

```python
{'name': 'Иван', 'age': 20}
```

---

### Получить значение по ключу

```python
person = {
    "name": "Иван",
    "age": 20
}

print(person["name"])

print(person.get("name"))
```

Результат:

```python
Иван
Иван
```

---

### Добавить новый ключ

```python
person = {
    "name": "Иван"
}

person["age"] = 20

print(person)
```

Результат:

```python
{'name': 'Иван', 'age': 20}
```

---

### Изменить значение

```python
person = {
    "name": "Иван",
    "age": 20
}

person["age"] = 21

print(person)
```

Результат:

```python
{'name': 'Иван', 'age': 21}
```

---

### Удалить ключ — pop()

```python
person = {
    "name": "Иван",
    "age": 20
}

person.pop("age")

print(person)
```

Результат:

```python
{'name': 'Иван'}
```

---

### Получить все ключи — keys()

```python
person = {
    "name": "Иван",
    "age": 20
}

print(person.keys())
```

Результат:

```python
dict_keys(['name', 'age'])
```

---

## 📌 Главное про dict

* Хранит данные в формате **ключ : значение**
* Получение данных происходит по ключу
* Можно добавлять, изменять и удалять значения
* Каждый ключ должен быть уникальным
