# Структуры данных в Python

Структуры данных нужны для хранения нескольких значений в одной переменной.

---

# 📋 List (список)

Список хранит данные в определённом порядке. Его можно изменять.

```python
numbers = [10, 20, 30]

print(numbers)
```

Результат:

```python
[10, 20, 30]
```

---

### Добавить элемент — append()

```python
numbers = [10, 20, 30]

numbers.append(40)

print(numbers)
```

Результат:

```python
[10, 20, 30, 40]
```

---

### Удалить элемент — remove()

```python
numbers = [10, 20, 30]

numbers.remove(20)

print(numbers)
```

Результат:

```python
[10, 30]
```

---


### Посчитать количество элементов — count()
Считает количество элементов в списке 
```python
numbers = [10, 10, 10, 20, 30]

print(numbers.count(10))
```

Результат:

```python
3
```

---

### Узнать количество элементов — len()

```python
numbers = [10, 20, 30]

print(len(numbers))
```

Результат:

```python
3
```

---

### Получить элемент по индексу

Индексация начинается с нуля.

```python
numbers = [10, 20, 30]

print(numbers[0])
```

Результат:

```python
10
```

---

## 📌 Главное про list

* Хранит данные по порядку
* Можно изменять
* Можно добавлять и удалять элементы
* Элементы имеют индексы
