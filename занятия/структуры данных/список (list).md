# Структуры данных в Python

Структуры данных нужны для хранения нескольких значений в одной переменной.

---

# 📋 List (список)

Список хранит данные в определённом порядке. Его можно изменять.

```python
numbers = [10, 20, 30]

print(numbers)
```

Результат:

```python
[10, 20, 30]
```

---

### Добавить элемент в конец — append()

```python
numbers = [10, 20, 30]
numbers.append(40)
print(numbers)
```

Результат: `[10, 20, 30, 40]`

---

### Вставить элемент по индексу — insert()

Вставляет элемент на переданную позицию (индекс), сдвигая остальные вправо.

```python
numbers = [10, 20, 30]
numbers.insert(1, 15) # Вставить 15 на место с индексом 1
print(numbers)
```

Результат: `[10, 15, 20, 30]`

---

### Удалить конкретный элемент — remove()

Удаляет первое совпадение элемента.

```python
numbers = [10, 20, 30, 20]
numbers.remove(20)
print(numbers)
```

Результат: `[10, 30, 20]`

---

### Удалить и получить элемент — pop()

Удаляет элемент по индексу (по умолчанию — последний) и возвращает его.

```python
numbers = [10, 20, 30]
last = numbers.pop()
print(last)
print(numbers)
```

Результат:
```
30
[10, 20]
```

---

### Посчитать количество элементов (совпадений) — count()

Считает количество определённых элементов в списке.

```python
numbers = [10, 10, 10, 20, 30]
print(numbers.count(10))
```

Результат: `3`

---

### Узнать количество элементов (длину списка) — len()

```python
numbers = [10, 20, 30]
print(len(numbers))
```

Результат: `3`

---

### Сортировка списка — sort()

Сортирует элементы списка (меняет сам список).

```python
numbers = [30, 10, 20]
numbers.sort()
print(numbers)
```

Результат: `[10, 20, 30]`

---

### Развернуть список — reverse()

Меняет порядок элементов на обратный.

```python
numbers = [10, 20, 30]
numbers.reverse()
print(numbers)
```

Результат: `[30, 20, 10]`

---

### Получить элемент по индексу

Индексация начинается с нуля. Можно использовать отрицательные индексы (-1 — это последний элемент).

```python
numbers = [10, 20, 30]
print(numbers[0])  # Первый элемент
print(numbers[-1]) # Последний элемент
```

Результат:
```
10
30
```

---

## 📌 Главное про list (список)

* Хранит данные по порядку (упорядочен)
* Можно изменять (mutable)
* Можно добавлять (`append`, `insert`) и удалять элементы (`remove`, `pop`)
* Элементы имеют индексы (отсчет начинается с `0`)
* Поддерживает повторяющиеся элементы
