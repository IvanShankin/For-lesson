# Краткая памятка по Python

## 1. Переменные

Переменная — это имя, под которым хранится значение.

```python
name = "Иван"
age = 15
height = 1.75
```

Вывод значения:

```python
print(name)
print(age)
```

---

## 2. Типы данных

### Целые числа (int)

```python
age = 15
score = 100
```

### Дробные числа (float)

```python
price = 99.99
height = 1.75
```

### Строки (str)

Текст записывается в кавычках.

```python
name = "Иван"
city = 'Москва'
```

### Логический тип (bool)

Может иметь только два значения:

```python
is_student = True
is_adult = False
```

---

## 3. Функция print()

Используется для вывода информации на экран.

```python
print("Привет!")
print(10)
print(True)
```

Можно выводить несколько значений:

```python
name = "Иван"
age = 15

print("Имя:", name)
print("Возраст:", age)
```

---

## 4. Функция input()

Позволяет получить данные от пользователя.

```python
name = input("Введите имя: ")

print("Привет,", name)
```

⚠️ `input()` всегда возвращает строку (`str`).

```python
age = int(input("Введите возраст: "))
```

---

## 5. Условные операторы

Позволяют выполнять разный код в зависимости от условия.

### if

```python
age = 18

if age >= 18:
    print("Вы совершеннолетний")
```

### if - else

```python
age = 15

if age >= 18:
    print("Вы совершеннолетний")
else:
    print("Вы несовершеннолетний")
```

### if - elif - else

```python
score = 75

if score >= 90:
    print("Отлично")
elif score >= 70:
    print("Хорошо")
else:
    print("Нужно подтянуть знания")
```

## 6. Логические операторы `and` и `or`

Иногда нужно проверять сразу несколько условий.

### `and` (И)

Условие будет истинным, только если **все проверки истинны**.

```python
age = 20
has_passport = True

if age >= 18 and has_passport:
    print("Можно путешествовать")
```

### `or` (ИЛИ)

Условие будет истинным, если **хотя бы одна проверка истинна**.

```python
day = "суббота"

if day == "суббота" or day == "воскресенье":
    print("Сегодня выходной")
```

### Пример с числами

```python
number = 15

if number > 10 and number < 20:
    print("Число находится между 10 и 20")
```

## 7. Сравнение значений

| Оператор | Значение         |
| -------- | ---------------- |
| `==`     | равно            |
| `!=`     | не равно         |
| `>`      | больше           |
| `<`      | меньше           |
| `>=`     | больше или равно |
| `<=`     | меньше или равно |

Пример:

```python
age = 15

if age >= 12:
    print("Можно смотреть фильм")
```

## 8. Простая программа

```python
name = input("Введите имя: ")
age = int(input("Введите возраст: "))

if age >= 18:
    print(name, "совершеннолетний")
else:
    print(name, "несовершеннолетний")
```

## Что нужно запомнить

* `int` — целые числа (`10`, `25`, `-7`)
* `float` — дробные числа (`3.14`, `1.5`)
* `str` — текст (`"Привет"`)
* `bool` — `True` или `False`
* `print()` — выводит информацию на экран
* `input()` — получает данные от пользователя
* `if`, `elif`, `else` — позволяют принимать решения
* Переменная хранит значение:

```python
name = "Иван"
age = 15
```

Python читает код сверху вниз и выполняет команды по порядку. 🚀
