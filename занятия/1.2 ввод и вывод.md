# Краткая памятка по Python: Ввод и вывод

## 1. Функция print()

Используется для вывода информации на экран.

```python
print("Привет!")
print(10)
print(True)
```

Можно выводить несколько значений, разделяя их запятой:

```python
name = "Иван"
age = 15

print("Имя:", name)
print("Возраст:", age)
```

---

## 2. Функция input()

Позволяет получить данные от пользователя.

```python
name = input("Введите имя: ")

print("Привет,", name)
```

⚠️ `input()` всегда возвращает строку (`str`). Если нужно получить число, используйте преобразование:

```python
age = int(input("Введите возраст: ")) # Для целых чисел
weight = float(input("Введите вес: ")) # Для дробных чисел
```

---

## Что нужно запомнить

* `print()` — выводит информацию на экран
* `input()` — получает данные от пользователя из консоли
* При получении чисел через `input()`, обязательно оборачивайте его в `int()` или `float()`.
